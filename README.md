# La Prima Couture

La Prima Couture is a website project for custom dress design and appointment booking.

The website allows users to create an account, log in, customize a dress, upload their own design, save their designs, and book an appointment with a designer.

## Features
- Sign up and login
- Custom dress design
- Upload custom design
- Save and manage designs
- Book appointments
- Responsive design
